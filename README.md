# 龙胤立志传 · Cheat Engine 工具箱

物品、武功、门派、弟子与外观管理的 CE 表，附秘籍目录及离线查询页面。

**[下载 Release 1.2](https://github.com/kristophor/LongYinLiZhiZhuan-CE/releases/tag/v1.2)** · [反馈问题](https://github.com/kristophor/LongYinLiZhiZhuan-CE/issues)

## 开始使用

1. 下载 Release 的 `LongYinLiZhiZhuan-release-v1.2.zip`，完整解压。
2. 启动游戏、读入存档，在 Cheat Engine 中连接游戏进程并加载 `LongYinLiZhiZhuan-v1.2.CT`。
3. 按需打开各管理入口。首次使用前保留一份游戏存档备份。
4. 秘籍目录手动加载同目录 `LongYinLiZhiZhuan-books.json`；`book-ranges` 与 JSON 保持同级。
5. `秘籍查询.html` 可直接在浏览器打开，无需连接游戏。

使用 CE 加载，无需安装 BepInEx 或替换游戏文件。表中包含 Lua 脚本；源码位于 `source/`。

## 功能

- 背包：搜索、筛选、复制、添加、删除物品；秘籍目录、本地范围图预览。
- 武功：等级与经验管理、遗忘、练至突破关口、直接红色突破、连续修炼与原生随机突破。
- 门派：资源、科研、加成与速度管理。
- 弟子：列表、忠诚与单名弟子完整属性编辑。
- 自创武功：草稿编辑、效果目录、触发/目标说明、装备/施放/升级位置建议。
- 外观：主角立绘、对话及战斗外观替换。
- 家中仓库入口、探索耐力、天赋管理等。

## 兼容性与验证范围

本项目针对 Unity IL2CPP 的特定游戏构建，包含 `GameAssembly.dll` 地址及结构偏移。游戏更新后可能失效；报错时请停止对应功能，并提供游戏版本、CT 版本及完整错误文字。

目录导出时记录的 GameAssembly SHA256 可在 JSON 中查看；该记录不是对后续游戏版本兼容性的保证。

Release 1.2 检查了 XML、记录 ID、Lua 语法、内嵌源码一致性、文件校验和及 ZIP 完整性。原生随机突破曾实测一轮 6→7 级；完整连续流程和所有效果组合未逐项实机验收。源码检查与模拟测试不等于全功能游戏验证。
